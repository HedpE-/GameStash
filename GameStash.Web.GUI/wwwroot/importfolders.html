Import Games Help

If some folders aren't detected by the engine and you want to include them in your local library (e.g. ISO games without an installer or non-standard directory structures), you can create a file named playarr.json inside the game folder with keys "Name" and "Type" (optional). Next time the root folder is scanned, the folder will appear here.

Conversely, if a discovered folder shouldn't be imported (such as updates or tools like RUNE), place an empty file named playarr.ignore inside that folder to skip it and all its subfolders.
